## CORE CONCEPTS

### 1. The Polygonal Sub-Grid Method
The traditional construction technique:
- Start with a regular polygon grid (triangle, square, hexagon, octagon, decagon, pentagon)
- Draw diagonals connecting vertices
- The resulting pattern of lines IS the girih pattern
- No measurement needed — purely compass and straightedge

### 2. Girih Tiles
Five specific tile shapes that tile the plane aperiodically (Penrose-like, before Penrose):
- **Decagon** (10-sided)
- **Pentagon** (5-sided)
- **Hexagon** (6-sided, bowtie-like)
- **Rhombus** (diamond)
- **Barrel-shaped hexagon**

These tiles match the internal angles of the pattern lines, making them a "decoding" of the geometry.

### 3. Five-Fold Symmetry (Quasicrystalline)
The Darb-i Imam shrine (Isfahan, 1453) features patterns with:
- Local 5-fold and 10-fold symmetry
- Never-repeating long-range order
- Matching rules identical to Penrose tilings (discovered 1974)
- Proof that medieval Islamic artisans understood quasicrystal geometry

### 4. Proportional Systems
Specific ratios govern all relationships:
- **√2** (1.414): Octagonal systems, square-based
- **√3** (1.732): Hexagonal, triangular systems
- **φ** (1.618): Pentagonal, five-fold systems
- **2+√3** (3.732): Specific to some star polygon constructions

### 5. The Strapwork Technique
Girih patterns rendered as interlaced bands:
- Lines become "straps" that weave over and under each other
- Creates illusion of 3D braided cord
- The weaving rule: at every crossing, one strap goes over, the other under
- Creates visual rhythm and topological complexity

## MATHEMATICAL FOUNDATION

### Girih Tile Matching Rules
```
For a valid girih tiling:
- Each edge has a specific length (relative to others)
- Each edge has a matching "type" (decorated with specific pattern)
- Tiles must connect edges of matching type
- The result: aperiodic long-range order with local 5-fold symmetry
```

### The Golden Triangle and Gnomon
```
Golden triangle: isosceles with angles 36°, 72°, 72°
Golden gnomon: isosceles with angles 36°, 36°, 108°
These subdivide infinitely, creating self-similar structure.
```

### Decagon Star Construction
```
1. Draw circle
2. Mark 10 equally spaced points (36° apart)
3. Connect every 3rd point → 10-pointed star
4. Connect every 2nd point → inner pentagon
5. Bisect edges → secondary pattern
6. Continue subdivision for density
```

### Quasicrystal Property
```
The Fourier transform of a perfect girih tiling:
- Sharp Bragg peaks (crystalline property)
- 10-fold rotational symmetry (impossible for periodic crystals)
- This is the definition of a quasicrystal
```
